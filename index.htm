Comandos Essenciais

git Init

Cria um repositorio Git na pasta atual ou inicia o Git no projeto.

git add .

adiciona todos os arquivos alterados ao Git ou prepara tudo para salvar.

git commit -m "[mensagem de comit]"

salva as alterações com uma mensagem ou registra o que eu fiz

git push -u origin main

envia os arquivos do Git para o GitHub ou manda meu projeto pro GitHub.

git fetch

verifica se o repositório remoto tem modificações em relação ao local

git pull

baixa as atualizações do GitHub para o seu PC, puxa as novidades do GitHub

git clone [link do repositorio]

liga ou conecta seu projeto local ao repositorio do GitHub.

git remote add origin [link do repositorio]

liga seu projeto local ao repositorio do GitHub

Utilize os comandos com cuidado, utilize espaço, feche as TAGs e mantenha a ordem do texto, (alt+shift+F) para alinhar o texto.
